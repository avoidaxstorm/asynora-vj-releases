# Maelstrom

Music-reactive visuals and DMX lighting for VRChat clubs, for macOS and Windows.

**Download:** see [Releases](../../releases/latest):
- macOS: `Maelstrom-<version>-mac.dmg`: open it and drag Maelstrom into Applications.
  The first time, right-click Maelstrom → Open (the app isn't signed with an Apple developer ID yet).
- Windows: `Maelstrom-<version>-windows-setup.exe`

Maelstrom updates itself from here: Advanced → Updates.

This repository only holds the installers.
