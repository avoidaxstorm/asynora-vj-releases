# Asynora VJ

Music-reactive visuals and DMX lighting for VRChat clubs, for macOS and Windows.
(Formerly called Maelstrom.)

**Download:** see [Releases](../../releases/latest):
- macOS: `AsynoraVJ-<version>-mac.dmg`: open it and drag Asynora VJ into Applications.
  The first time, right-click Asynora VJ → Open (the app isn't signed with an Apple developer ID yet).
- Windows: `AsynoraVJ-<version>-windows-setup.exe`

Asynora VJ updates itself from here: Advanced → Updates.

This repository only holds the installers.
